# Site académique bilingue — Daniel Ndjodo Bessala

Site statique prêt pour GitHub Pages, Netlify, Vercel ou tout hébergement web classique.

## Fichiers
- `index.html` : structure principale
- `styles.css` : design responsive, thème clair/sombre
- `script.js` : navigation, thème, barre de progression et bascule Français / English
- `photo-daniel.jpeg` : photo de profil
- `CV_Daniel_Ndjodo_Bessala.pdf` : CV académique

## Bilingue
Le bouton `FR / EN` dans la barre de navigation traduit le contenu sans recharger la page. La langue choisie est mémorisée dans le navigateur via `localStorage`. Au premier affichage, le site utilise automatiquement la langue du navigateur si elle est française, sinon l'anglais.

## Publication sur GitHub Pages
1. Créer un dépôt GitHub, par exemple `daniel-ndjodo-bessala.github.io`.
2. Déposer tous les fichiers à la racine du dépôt.
3. Dans Settings > Pages, choisir la branche `main` et le dossier `/root`.
4. Le site sera ensuite accessible à l'adresse GitHub Pages indiquée par GitHub.
